# CivicSide — Minecraft Server Site

Красивая HTML-страница статуса Minecraft-сервера.

## Что есть

- Крупное название сервера
- Блок с IP-адресом и кнопкой «Копировать IP»
- Текущий онлайн и статус сервера (зелёная/красная точка)
- Автообновление каждые 30 секунд через API [mcsrvstat.us](https://mcsrvstat.us)
- Тёмный игровой дизайн с анимациями

## Как настроить

1. Открой файл `index.html`
2. Найди комментарий:
   ```js
   // ============================================
   // ВПИШИ СЮДА IP СВОЕГО СЕРВЕРА:
   // Например: "play.civicside.ru" или "123.45.67.89"
   // ============================================
   const SERVER_IP = "play.example.com";
   ```
3. Замени `play.example.com` на IP или домен своего сервера.

## Просмотр

Открой `index.html` в браузере или залей GitHub Pages.
